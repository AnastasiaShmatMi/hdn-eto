# ХДН-это

Один общий стол на весь зал.

Гость по QR пишет имя и нажимает «Готов к игре». Слова и клетки появляются только после «Начать игру». На экране зала в этот момент написано «Игра началась». Гость расставляет девять слов и нажимает «Готово». Когда ведущий нажимает «Завершить игру», все видят правильный вариант. Три совпавшие клетки в ряд, столбец или по диагонали — бинго.

## Три адреса

- Карточка гостя, её же кодирует QR: https://hdn-eto.netlify.app/
- Стол ведущего: https://hdn-eto.netlify.app/host
- Экран зала: https://hdn-eto.netlify.app/screen

## Как играть

1. Откройте экран зала на проекторе. Пока идёт набор, там QR и адрес карточки.
2. Гость пишет имя и нажимает «Готов к игре». Слов пока нет.
3. Если правильный порядок нужно поменять, ведущий нажимает «Поменять порядок», переставляет слова и сохраняет.
4. Ведущий нажимает «Начать игру». На телефонах появляются слова в два столбца и клетки, на экране зала — «Игра началась».
5. Гость нажимает «Готово». У ведущего сразу подсвечиваются совпавшие клетки и бинго. «Завершить игру» показывает правильный вариант всем остальным. Карточки при этом остаются.
6. «Сбросить игру» спрашивает подтверждение и очищает клетки у всех. Правильный вариант ведущего остаётся, набор открывается снова.

Бесплатный сервер засыпает, если к нему долго никто не обращается. Первый заход после сна может идти долго: откройте сайт заранее. Новый деплой обнуляет стол.

## У себя на компьютере

В папке `Server`: `npm ci`, затем `npm test` и `npm start`.
В папке `Client`: `npm ci`, затем `npm run dev`.
Карточка откроется локально, а запросы к серверу пойдут через прокси `/api`.
