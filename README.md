# ХДН-это

Один общий стол на весь зал.

Гость с телефона открывает карточку, пишет имя и ставит в клетки слова из списка, которые считает нужными. У ведущего на экране лежит правильный вариант. Пока идёт набор, телефон не говорит, совпал ли порядок. Когда ведущий начинает игру, на телефоне сразу видно, сколько клеток совпало с шаблоном. Ведущий называет слова. На экране зала сначала большой QR, а после старта — слово, которое звучит сейчас. Три клетки в ряд по горизонтали, вертикали или диагонали — бинго. Свободной клетки в центре нет.

## Три адреса

- Карточка гостя, её же кодирует QR: https://hdn-eto.netlify.app/
- Стол ведущего: https://hdn-eto.netlify.app/host
- Экран зала: https://hdn-eto.netlify.app/screen

## Как играть

1. Откройте экран зала на проекторе. Пока идёт набор, там QR и адрес карточки.
2. Гость наводит камеру, пишет имя, расставляет слова из списка под «ХДН-это» и нажимает «Готово». До старта порядок можно поправить. Совпадение появится только после старта.
3. Ведущий на ноутбуке нажимает «Начать игру». Новые карточки больше не принимаются.
4. Ведущий называет слово. Если оно есть на карточке, клетка загорается сама.
5. «Вернуть набор» снова открывает приём карточек и стирает названные слова. «Сбросить стол» спрашивает подтверждение и убирает ещё и карточки.

Бесплатный сервер засыпает, если к нему долго никто не обращается. Первый заход после сна может идти долго: откройте сайт заранее. Новый деплой обнуляет стол.

## У себя на компьютере

В папке `Server`: `npm ci`, затем `npm test` и `npm start`.
В папке `Client`: `npm ci`, затем `npm run dev`.
Карточка откроется локально, а запросы к серверу пойдут через прокси `/api`.
