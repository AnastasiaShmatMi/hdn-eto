# ХДН-это

Один общий стол на весь зал.

Гость с телефона открывает карточку, пишет имя и ставит в клетки слова из списка, которые считает нужными. У ведущего на экране лежит правильный вариант, и его можно переставить. Пока идёт набор, телефон не говорит, совпал ли порядок. Когда ведущий начинает игру, на телефоне сразу видно, сколько клеток совпало с шаблоном. Три совпавшие клетки в ряд, столбец или по диагонали — бинго: на телефоне появляется «БИНГО», у ведущего — список этих имён. На экране зала сначала большой QR, а после старта — «Игра началась».

## Три адреса

- Карточка гостя, её же кодирует QR: https://hdn-eto.netlify.app/
- Стол ведущего: https://hdn-eto.netlify.app/host
- Экран зала: https://hdn-eto.netlify.app/screen

## Как играть

1. Откройте экран зала на проекторе. Пока идёт набор, там QR и адрес карточки.
2. Гость наводит камеру, пишет имя, расставляет слова из списка под «ХДН-это» и нажимает «Готово». До старта порядок можно поправить. Совпадение появится только после старта.
3. Если правильный порядок нужно поменять, ведущий нажимает «Поменять порядок», переставляет слова и сохраняет.
4. Ведущий нажимает «Начать игру». Новые карточки больше не принимаются, и на телефонах появляется результат.
5. «Завершить игру» показывает правильный вариант на экране зала. Карточки при этом остаются.
6. «Сбросить игру» спрашивает подтверждение и очищает клетки у всех. Правильный вариант ведущего остаётся, набор открывается снова.

Бесплатный сервер засыпает, если к нему долго никто не обращается. Первый заход после сна может идти долго: откройте сайт заранее. Новый деплой обнуляет стол.

## У себя на компьютере

В папке `Server`: `npm ci`, затем `npm test` и `npm start`.
В папке `Client`: `npm ci`, затем `npm run dev`.
Карточка откроется локально, а запросы к серверу пойдут через прокси `/api`.
